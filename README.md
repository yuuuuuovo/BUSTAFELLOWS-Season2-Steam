## 补丁安装

### Windows 版本安装方法

1. 安装之前需要关闭一切杀毒软件，无论是系统自带的防护软件，还是360安全卫士之类第三方杀毒软件。否则容易将补丁当成病毒删除或者破坏文件内部。
2. 下载好补丁文件，是一个 exe 安装文件。将补丁放到游戏的根目录下，双击补丁，稍等一会即可出现汉化免责声明，不同意可退出安装补丁。
3. 点击同意才能进行到下一步，进入后点击安装补丁，会将补丁文件安装到游戏中，安装成功后，打开游戏就是汉化版本的游戏。
4. 想恢复英文版的游戏，也是双击补丁安装文件，选择卸载，中文补丁就会卸载，游戏恢复英文版。

### SteamOS 版本安装方法

1. 概括来说就是把汉化补丁添加到 Steam 游戏库，使用兼容层打开安装以后，启动游戏，就会变成中文版本。（文件夹下有操作视频）

## 关于游戏汉化你可能关心的

### 我做的

- 汉化了所有剧情文本、非贴图的 UI 文本、流程图文本、设置文本、各种系统提示等，个人估算汉化率 95% 以上。
- 图片只重做了 help 的图，因为 BF 系列的 PC 操作一向都很迷，希望 help 能帮大家快速熟悉游戏系统。
- 重新在 Unity 里做了和日文字体相近的中文字体，原本的日文字体无法显示中文，因为是日系中文字体，所以部分字体显示的会是日本汉字写法。

### 你可能介意的

- 女主角名字无法使用中文。
- 文本翻译使用 DeepL 机翻，会出现名字当成单词翻译、地名当成单词翻译、多义词翻译随机、上下文翻译衔接不好、专有名词和 BF1 官中翻译不一致、同一句话翻译不同等问题。即使用 DeepL 跑了好几遍翻译，人工也修改了很多发现的问题和容易出现问题的地方，难免有漏下或者有问题的，还请见谅。
- 姓、地名、商场名和其余各种专有名词有的保留英文，有的翻译成了中文。
- 因为此次汉化大部分是人工操作，所以有可能会有一些出错的地方，或者是游戏运行的 bug。还有一部分文本是在代码里，为了和英文字节数量对上，中文只能精简又精简。设置里有一个 SE（Sound Effect）和 BGM(Background Music) 用的单词缩写，中文无法实现一个字翻译，所以这是没有翻译的已知地方。
- 除了 help 以外的图片都没有汉化，视频没有汉化。过场动画还有一部分 cg 都是视频，部分视频开头的文字如果没有汉化，可以在历史记录里看到翻译。
- **禁止将我的补丁使用在盗版游戏上，盗版游戏出现的BUG一律不解决，也请不要评论或私信装成正版玩家来联系我！**
- 如果无法接受以上问题，请等待官中或者人工翻译，祝大家游戏愉快！
